Required for most tools — it signs you into shared workspaces securely.

BrandSeoTools Access v3.0.1

One-click sign-in to every tool you subscribe to. No passwords to copy, no shared credentials in plain sight — the extension handles sessions for you.

On a phone? Desktop is recommended — but the extension can also run on mobile browsers that support Chrome extensions:
AndroidInstall Kiwi Browser (Play Store) → open chrome://extensions → enable Developer mode → Load unpacked → pick the extracted folder → log in. Same as desktop from then on.
iPhoneOrion Browser supports some Chrome extensions — compatibility isn't guaranteed. If it fails, use a desktop.
Tools marked Cloud access work in any browser, no extension needed.

Installation — 4 steps

1
Download and unzip

Click Download above and extract the .zip to a folder you’ll keep (e.g. Documents/BrandSeoTools).

2
Open extensions page

In Chrome/Edge/Brave, go to chrome://extensions and turn on Developer mode (top right).

3
Load unpacked

Click Load unpacked and select the extracted folder. The BrandSeoTools icon appears in your toolbar.

4
Pin it and you’re done

Pin the extension, then open any tool page — access happens automatically from then on.

Can’t install extensions? Tools marked Cloud access (like CapCut) work without it — and support can enable cloud sessions for other tools on request.

Requirements

  • Chrome, Edge, Brave or Arc — v110+
  • Windows, macOS or Linux desktop
  • Any active subscription
  • Only runs on tool pages you open from here

Troubleshooting

  • Extension vanished after update?
    Re-run Load unpacked — browser updates sometimes remove sideloaded extensions.
  • “Access denied” on a tool?
    Check it’s under Your tools on the Dashboard and hasn’t expired.
  • Stuck on a blank page?
    Sign out of the tool’s own account first — sessions can conflict.
